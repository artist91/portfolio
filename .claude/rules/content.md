# Content Rules

## 포트폴리오 섹션 구성
1. **Hero** — 이름, 직군 한 줄 소개
2. **About** — 짧은 자기소개 (3-5문장), 철학이나 작업 방식
3. **Work** — 프로젝트/작업물 이미지 + 제목 + 간단한 설명
4. **Contact** — 이메일 또는 SNS 링크

## 텍스트 원칙
- 간결하게: 한 문장으로 말할 수 있으면 두 문장 쓰지 않는다
- 직접적으로: 수식어보다 사실을 먼저
- 전문적이되 딱딱하지 않게

## 언어
- 기본 언어: 한국어와 영어 병행 여부는 사용자와 결정
- 직군 표기: Branding Planner / Designer / Writer

## Hero 섹션
- 이름은 크고 명확하게
- 직군은 한 줄로 간결하게
- 부가 설명 없이 임팩트 있게

## About 섹션
- 자기소개는 3-5문장 이내
- "저는 ~합니다" 형식보다 능동적인 표현 권장
- 작업 철학 또는 관심사 1-2가지 포함

## Work 섹션
- 프로젝트당 이미지 1-3장
- 제목 + 카테고리(브랜딩/디자인/글쓰기) + 한 줄 설명
- 상세 설명은 최소화, 이미지가 말하게 한다

## Contact 섹션
- 이메일 주소 또는 링크만
- 긴 문구 없이 짧은 초대 문장 1개
- SNS는 최대 2개만 노출

## 금지 사항
- 과도한 자기 홍보 문구 금지
- "세계 최고", "최우수" 등 과장 표현 금지
- 불필요한 수식어 금지
